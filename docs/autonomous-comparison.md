# Formation autonome Claude + ChatGPT — 11 septembre 2026

## Analyse du site de référence
La page publique https://tixu.ai/ a été consultée dans le navigateur. Elle présente un parcours de 28 jours, un questionnaire de personnalisation, des leçons courtes, de la pratique avec outils et des certificats. Son programme pédagogique détaillé n’est pas accessible sur cette page. Aucun cours privé n’a été consulté ou copié ; aucune équivalence exhaustive avec son catalogue n’est revendiquée.

## Réalisation originale AI IMMO
28 ateliers regroupés en 7 chapitres, chaque atelier avec explication, cas fictif, tâche, deux prompts de départ volontairement identiques pour un essai équitable, relance de contrôle, critères de comparaison, carnet sauvegardé et 3 questions corrigées côté serveur. Les deux premières questions sont contextualisées ; la troisième rappelle le protocole commun. Le carnet utilise les notes privées du membre ; les tentatives utilisent le stockage existant. Les 48 leçons accompagnées restent distinctes.

Les liens ouvrent Claude et ChatGPT dans les comptes de l’apprenant. Il n’y a ni exécution API ni facturation fournisseur intégrée. La recommandation de rythme est une aide locale simple, pas un diagnostic adaptatif. Les notes de qualité sont une auto-évaluation, pas un benchmark exécuté par le site. Pas de certificat professionnel annoncé. Le seuil du QCM est 80 %, ce qui exige 3 bonnes réponses sur 3 avec ce format.
